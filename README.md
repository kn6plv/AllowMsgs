AREDN LAN Message Firewall
===

An AREDN LAN based firewall filter which restricts the use of the AREDN LAN network to only texting/messaging apps.
Current it allows:

* WhatsApp
* iMessage
* Google RCS
* Signal
* Facebook Messenger
* Telegram
* Slack
* Discord

Only texts are allowed. Larger media (e.g. photos, videos, etc.) are blocked.
